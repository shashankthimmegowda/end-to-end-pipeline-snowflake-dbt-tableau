Overview

What This Project Does

A production-grade data engineering solution for processing raw sales data into actionable business intelligence.

  • Ingests semi-structured CSV sales data from AWS S3 into Snowflake using the COPY INTO command
  • Flattens nested JSON columns in Snowflake using LATERAL FLATTEN to extract each dimension table
  • Uses dbt incremental models (materialized='incremental') to build a full Star Schema
  • Maintains a live Tableau connection to Snowflake for real-time dashboard refreshes
  • GitHub Actions CI/CD automates dbt test → dbt run → deploy on every commit

FACT_SALES — Central Table
Joins raw sales with dim_product to compute total_revenue, total_cost, and total_profit per sale. Incremental with unique_key='SaleID'.
6 Dimension Tables
Customer, Location, Product, Promotion, Review, Shipping — each built by using LATERAL FLATTEN to unpack nested JSON columns from the raw source table.
Incremental Processing
Every model processes only records with IDs greater than the current max, making each dbt run fast and cost-effective in Snowflake's compute model.
Data Quality Tests
Every primary key tested for unique + not_null via schema.yml. Custom macro check_positive_quantity enforces business rules.

dbt

Incremental dbt Models

Every model uses materialized='incremental', processing only new records on each run — ensuring speed and cost efficiency.

⚡
Performance
Only new records processed — no full-table scans on every run.
💰
Cost-Effective
Reduced Snowflake compute time means significantly lower cloud bills.
🔄
Data Freshness
Near real-time updates without the latency of a full table rebuild.
🛡️
Error Isolation
Easier to identify and fix errors in the latest batch without reprocessing all data.

Automation

CI/CD with GitHub Actions

Every commit to main triggers a fully automated test-and-deploy pipeline — zero manual intervention required.

1
Test
Run dbt test to validate all data quality rules — unique keys, not-null constraints, and custom check_positive_quantity macro. Failures block deployment.
  dbt test
2
Run
If all tests pass, dbt run executes all incremental transformations and updates the Star Schema tables in Snowflake with the latest data.
  dbt run
3
Deploy
Validated models land in production Snowflake. Tableau's live connection automatically picks up the latest data — dashboards update without any manual refresh.
